# Wireguard Dashboard
This dashboard shows the traffic generated by the peers

### How to use it
- First create a file called **peers.txt** under `/usr/local/bin/wg-dashboard/`
- In the **peers.txt** fill it with the following format:

`<peer preshared key>=<friendly name>`

**Example**:

```
GpnpQjXVvacd6AtlHQ8I1pWK2rvSLziffdsfdfdsuTwere==Ahmed
3JX6QfTgfyXLt2kBl5OaCSkdEVEe404odsfd345YrP9RHE==Mahmoud
```

- To get the peer preshared key, us the command `sudo wg show all dump` - the second column is the preshared key of the peer.
- To start the dashboard, run the following command:

`sudo python3 wg_dashboard.py --bind 0.0.0.0 --port 8080 --interval 5 --names /usr/local/bin/wg-dashboard/peers.txt --retention-hours 720`

- Now you can access it through this URL: `http://<ServerIP/Name>:8080/`
- You can also create a service to run this command by a file **wg-dashboard.service** under `/etc/systemd/system/` with the following content:
```
Description=WireGuard Dashboard Service
After=network.target

[Service]
Type=simple
WorkingDirectory=/usr/local/bin/wg-dashboard
ExecStart=python3 /usr/local/bin/wg-dashboard/wg_dashboard.py --bind 0.0.0.0 --port 8080 --interval 5 --names /usr/local/bin/wg-dashboard/peers.txt --retention-hours 720
Restart=on-failure
User=root

[Install]
WantedBy=multi-user.target

```
- Then run the following command:
`systemctl enable wg-dashboard && systemctl start wg-dashboard`
- To check the status of the service run the command:
`sudo service wg-dashboard status`
